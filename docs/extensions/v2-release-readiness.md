## v2 Adoption Priorities (Authoritative)

ai-netsim v2 prioritizes **usable, trustworthy validation**, not feature count.

### Tier 1 — Release Blocking

These must be present and working well:

- Invariant packs (at least 1–2 high-quality)
- Topology + validation examples (simple + realistic)
- Scenario templates (at least 1 deterministic failure scenario)
- Atomic test usability (clear, simple, reliable)

---

### Tier 2 — Strongly Recommended

These significantly improve usability and adoption:

- State capture profiles (basic set)
- AI advisory (failure explanation, optional only)

---

### Tier 3 — Post-Release

These are valuable but not required for v2 release:

- NOS capability declarations
- Candidate config templates
- Advanced or domain-specific invariant packs
- Expanded AI modules

---

### Core Principle

Adoption comes from **usable, trustworthy validation — not feature count**.

---

### v2 Release Criteria (User Perspective)

ai-netsim v2 should ship when a user can:

- run a topology
- see a failure
- understand it
- trust the result

If these are true, the system is ready — even if additional features are not yet implemented.
