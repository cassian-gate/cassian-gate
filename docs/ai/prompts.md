# Prompt snippets (Reusable)

## Explain-first instruction
"Explain current behavior from artifacts/code first. Then propose the smallest safe change, list files touched, and define verification."

## No-authority reminder
"AI is advisory only. Do not change verdicts, exit codes, or execution semantics. Consume artifacts only."

## Fail-fast reminder
"If anything is ambiguous, fail fast before execution. No silent defaults."

## Scope guardrail
"Do not add lab/exploration features. Focus on deterministic validation."
