# contrib/nos

Reserved structural category for future NOS bundle evolution.

Set 1 status:

- structural only
- non-executable
- non-authoritative
- no runtime discovery
- no runtime loading
- no plugin behavior
- no NOS runtime support

Important boundary:

The presence of `contrib/nos/` does not mean NOS bundles are operational in v2.

It does not imply:

- runtime support
- readiness integration
- discovery/loading
- support claims for user-provided NOS content

Declarative NOS bundle support is later work, outside Set 1.
